# Hangman Game 🎮

A simple command-line Hangman game built using Python.

## 📌 Features
- Random word selection
- Categories (Fruits, Animals)
- Limited attempts
- Hint system
- Replay option

## 🛠️ Technologies Used
- Python
- Random module

## ▶️ How to Run
1. Install Python
2. Download this project
3. Run the file:
   python hangman.py

## 💡 How to Play
- Guess one letter at a time
- You have 6 attempts
- At 3 attempts, a hint will be given
- Guess the word before attempts run out!

## 📷 Sample Output

Word: _ _ _ _ _
