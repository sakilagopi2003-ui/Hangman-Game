# 🎮 Hangman Game (Python)

This is a simple command-line Hangman game developed using Python.  
The game randomly selects a word from a category and the player has to guess it letter by letter.

## 📌 Features
- Random category selection (Fruits, Animals)
- Limited attempts (6 chances)
- Tracks guessed letters
- Hint system when attempts reach 3
- Replay option after game over

## 🛠️ Technologies Used
- Python
- Random module
